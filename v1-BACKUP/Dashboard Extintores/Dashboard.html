Selecionar Fonte

Escolha de onde o dashboard deve ler os dados. A escolha fica salva neste navegador.
1. Google Sheets (Web App)
Cole a URL do Web App do Apps Script (a mesma URL usada no formulário no campo "URL do Web App").
2. Arquivo Excel
Leia um arquivo Excel (.xlsx/.xls) da sua máquina e atualize o dashboard sem conectar na nuvem.
